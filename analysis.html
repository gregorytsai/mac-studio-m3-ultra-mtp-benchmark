技術與分析

把「這批資料顯示什麼」與「還不能推論什麼」分開，讓設定建議有可追溯的依據。

測試環境與資料來源

NAS 環境紀錄：Mac Studio、Apple M3 Ultra，32 核心 CPU（24 效能＋8 節能），256GB 統一記憶體；Darwin 25.6.0 arm64。GPU 核心數未記錄，因此不補推。

推論環境記載 llama.cpp v0.7.0、commit 620d2225c、Metal、f16 KV cache 與 Metal peer memory。這些是原環境檔的紀錄，未在本次整理時重新登入測試機驗證。

--host 127.0.0.1 --port 8088
--jinja --flash-attn on --n-gpu-layers all
-c 16384 -b 2048 -ub 2048
temperature = 0.7
max_tokens = 4096
runs per prompt = 5

6 模型 × 各自可用設定 × 5 題，共 250 個條件、1,250 次執行。五模型有 baseline＋Q4/Q8×N1–4；Qwen 3.8 27B 只有 baseline＋Q4×N1–4。各設定的 context window 都是 16,384，沒有操弄 window 大小。輸入長度則隨題目與 tokenizer 不同。

來源不一致的處理：舊 README 說 Flash Next 只測 baseline，但 JSON 有 Q4/Q8、N1–4 且接受率非零，故依實際數值記錄分析。舊報表程式的版本字樣是 v0.6.0，環境檔寫 v0.7.0，runner 也有版本回退邏輯；無完整執行 log，不能保證每次執行的二進位版本相同。E4B Q4 與 Q8 都標為 94MB，實際 GGUF 型別及檔案大小尚未驗證。

數值如何計算

  1. 每個模型×設定×題目，先算 5 次生成速度的算術平均。
  2. 在同模型、同題目內，除以不開 MTP 的速度，得到加速比。
  3. 對加速比取幾何平均；模型等權重，兩類任務各佔 50%，類內題目等權重。

共同設計使用 Q4。Q8/Q4 比較只用五個條件完整的模型，於同題目、同 N 配對。baseline 不具有 Q，不複製成兩份當作獨立觀察。

加速比 = mean(speed_MTP) / mean(speed_baseline)
速度提升 (%) = (加速比 - 1) × 100
彙整 = exp(weighted_mean(log(加速比)))

1.41× 約等於每秒輸出多 41%。固定輸出量時，僅生成階段的時間比例約為 1/1.41；這不是實測總等待時間的換算，prefill 與產出量仍會影響整體耗時。

七個問題，可以回答到哪裡？

問題本次能回答的範圍
1. Context長度與題目內容混淆；window 固定，無法識別獨立主效果。
2. MTPQ4 N1–4 平均提升 +40.7%；是本批資料的描述性平均。
3. Q五模型同條件配對：Q8 相對 Q4 -1.3%。
4. N共同 Q4 設計 N3 最高，但與 N2、N4 接近。
5. N × 任務N1→N4 的 Agent/輔導比值之比為 1.1767。
6. MoE × NMoE/非 MoE 的 N1→N4 比值之比為 0.7573；不能歸因架構本身。
7. N × 任務 × 大小可比較各模型的曲線，無法單獨識別模型大小；最佳 N 是結果衍生值。

穩定度、資料限制與下一輪測試

  • 排除各條件第一次執行後，Q4 平均提升 +40.8%；12 個模型×任務組合的最佳 Q4 N 均不變。
  • 有 14 個條件的第一次執行仍有快取，不能一律視為完全 cold。
  • 輸出範圍為 1,022–4,096 tokens；181 次恰達 4,096 上限，但未存停止原因，無法逐筆確認截斷。
  • Q4 MTP 的平均 wall time 比值下降約 28.7%，輸出量平均差約 −0.15%；個別條件的產出量仍有差異。
  • 條件內生成速度的變異係數中位數 1.68%、最大 14.02%。最快與次快相差很少時，應在新批次再測。
  • 五次執行是技術重複，不是五道獨立題目。本報告不將 1,250 筆當成獨立樣本計算 p 值或一般化信賴區間。
  • 原 runner 固定順序測試，未指定 seed，且沒有硬體溫度、功耗或背景負載紀錄。測量不能排除批次、順序等影響。
  • 接受率不是回答正確率。未評分內容品質，也沒有完整 Agent 工具執行的成功率資料。

下一輪應讓每類任務有多道獨立題目，每題交叉多種輸入長度，控制輸出預算，隨機化設定順序並跨批次重複；分開測 cold 與 warm。先用一組題目挑 N，再在保留題目驗證。模型大小或架構效果需要更多可匹配的模型，不能只增加同一設定的重跑次數。
